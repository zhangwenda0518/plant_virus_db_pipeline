Overview

The Phylogeny module offers two views of plant virus evolutionary relationships on one page (/phylo/, tab switcher in the top bar) that use different conventions: the taxonomy tree shows set nesting (who contains whom), while the molecular trees are sequence-inferred and usually built from a single gene region, not the whole family.

Taxonomy tree — /phylo/ (default tab)

The ICTV MSL41 hierarchy: 48 plant virus families, 214 genera, 2,684 species (2,997 taxa shown at family level).

  • Expand to Family / Genus / Species — switch the depth the tree is drawn at; the default keeps the whole tree readable
  • Search by family, genus or species; scientific names and common abbreviations (CMV, TSWV, …) are supported
  • Non-plant viruses — adds the grey backbone of realm/kingdom/phylum/class/order nodes that share an order with a plant virus, plus the 73 non-plant families inside those orders; they are dead ends and cannot be expanded
  • Species labels and colour by family display toggles; Rectangular / Circular layout switch
  • Reset / Collapse / PNG actions; the sidebar family list shows species counts per family (Geminiviridae 558, Potyviridae 264, …)

ICTV molecular trees — /phylo/ “Molecular trees” tab (old /phylo/molecular/ redirects here with parameters)

Official maximum-likelihood phylogenies released by ICTV Report chapters: 25 families, 38 trees, 3,341 sequences (36/38 strictly bifurcating). These are the published chapter figures (Fig 1–Fig 6), not species-complete family phylogenies: tip sets are often far smaller than the family's species list, can be gene fragments or protein accessions, and may include sequences from other families used as outgroups. Read the family label as "which chapter published this figure", not "every tip belongs to this family".

  • Dataset — pick a family, then a figure; each tree is the figure published in the corresponding ICTV Report chapter
  • Support filter — collapse clades below a support threshold; nodes without a support value are always kept
  • Display — scale by branch length, show support values, tip labels, colour tips by genus; Phylogram / Circular layouts
  • Find taxon — marks every tip whose name matches and reports the smallest clade containing them all
  • Fit width / Reset / PNG actions; genus is mapped from ICTV MSL41 (family-constrained) since the tree files carry no taxonomic ranks
Tip: Use the taxonomy tree to answer "which family does this species belong to, and what else is in its order"; use the molecular trees to answer "how are these species related by sequence". When a species is missing from a molecular tree, it simply was not a tip in that chapter's figure — check the per-family index linked at the top of the molecular tree page.
