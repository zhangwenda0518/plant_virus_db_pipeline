Vector-Host DB — Vector-Host Database

Overview

Vector-Host DB integrates insect vector and plant host association data through a dual-source strategy: VIP-DB (1,375 experimentally validated virus–vector–host triplets across 447 viruses) and the WUR Plant Virus Transmission Database (1,654 virus records). Merging them yields 1,803 virus entries in total, of which 447 carry vector associations, 1,186 carry controlled-vocabulary transmission routes, and 9,958 literature links tie the relations back to 4,687 papers. Each association includes key parameters such as vector taxonomy, transmission mode, acquisition period, and inoculation period.

Quick Start

  1. Open /vector/ and enter a virus name in the search box
  2. View the vector list for that virus, including vector species, taxonomic information, and transmission parameters
  3. Filter by vector type: aphid, whitefly, thrips, leafhopper, mealybug, etc.
  4. View transmission modes: persistent, non-persistent, semi-persistent
  5. Browse the host plant range for that virus to understand its natural host spectrum
