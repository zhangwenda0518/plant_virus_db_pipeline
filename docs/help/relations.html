Virus–Vector–Host Relations

One entry point for every plant virus relationship view — association flow, networks, and the evidence library

Association flow — virus taxonomy (left) vs host taxonomy (right), 15,197 associations

Overview

The Relations module gathers all four relationship views behind a single set of tabs. The underlying association data is built from 211,132 GenBank accessions and resolves to 15,197 virus–host associations covering 5,134 virus species × 3,702 host species. The vector side merges two sources into 1,803 virus entries — VIP-DB supplies 447 viruses with vector associations (1,375 validated triplets, 120 of them virus–vector only) and WUR adds transmission records for 1,654 viruses. 9,958 literature links connect the relations to 4,687 papers, and 1,186 viruses carry controlled-vocabulary transmission routes.

The Four Views

1. Association flow (Sankey)

Virus taxonomy (order → family → genus → species) on the left, plant host taxonomy (kingdom → order → family → genus → species) on the right. Every ribbon is one virus–host association; link width equals the number of supporting GenBank accessions.

2. Virus–host network

A force-directed graph of all plant virus–host associations, for exploring which viruses cluster around which host lineages.

3. Vector–virus–host network

Triplet network of the 1,375 experimentally validated virus–vector–host records, connecting vector species to the viruses they transmit and the plants they infect.

4. Vector & evidence library

Focused tables over all 1,803 merged virus entries, 1,186 of which carry controlled-vocabulary transmission routes, with faceted filtering and 9,958 literature evidence links behind each relation.

Quick Start

  1. Open /relations/ — you land on the Association flow Sankey
  2. Use the search box to jump to a virus or host (abbreviations such as TSWV, CMV are supported via alias table)
  3. Click a node to drill one level deeper (order → family → genus → species); click a crumb in the drill path to go back
  4. Toggle direction with Virus → Host / Host → Virus; switch what counts as "plant" with the sidebar filters
  5. Export the current view with PNG or CSV buttons, or Reset to clear all drills
  6. Switch views with the tabs at the top: Virus–host network, Vector–virus–host network, Vector & evidence library

Filters

  • Plant hosts only (incl. algae) — default on; excludes associations to non-plant hosts
  • Include records without host annotation — off by default; turn on to see viruses whose host is unknown
  • Top N — nodes beyond the top N are merged into "Other" to keep the chart readable
Tip: The Sankey answers "which virus groups infect which plant lineages"; the library view answers "what is the evidence for this single record". For a field isolate workflow, drill the Sankey down to genus, then jump to /primers/ for detection primers of the candidate species.
