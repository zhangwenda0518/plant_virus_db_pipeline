📚 Data Resources

Reference DB

/photos/

Virus–Vector–Host Relations

/relations/

Every relationship view in one place: host–virus association Sankey, virus–host network, vector–virus–host triplet network, and the vector & evidence library. 15,197 pairs from 211,132 GenBank accessions; 1,375 validated vector triplets over 447 viruses.

Plant EVE Landscape

/eve/

Endogenous viral elements across 1,527 plant genomes and 284 host families — 150,136 decontaminated loci. Eight linked perspectives: virus taxa, host families, DNA/RNA duality, matrix, ancient infection, amplification, RT phylogeny, QC.

Vector–Host DB

/vector/

Insect vector and plant host interaction database. 1,803 merged virus entries across VIP-DB and WUR, of which 447 carry vector associations (1,375 validated triplets) with transmission mode and host range.

Primer Database

/primers/

83,830 unique PCR/qPCR primer pairs for 4,789 plant virus species (66,891 rated RECOMMENDED). Includes degenerate primers and whole-genome tiling designs.

1KP Virome

/onekp/

Virus detection across 1,341 plant transcriptomes from the OneKP project. 96 virus species (118 high-confidence detections) with interactive coverage and prevalence analysis.

UniProt Structure Atlas

/structures3d/#atlas

Structure coverage reconciliation for 4,810 UniProt plant-virus proteins: 218 experimental PDB entries, 435 current AFDB models, RVPSD cross-links, 90.8% BFVD cluster coverage. Protein search, per-virus coverage table, 3D viewer with pLDDT coloring. Now the Coverage atlas tab of /structures3d/ — coverage reconciliation, per-species completeness and the pending-prediction gap tiers all on one page (the old Statistics panel tab was merged in on 2026-10-08).

Virus Explorer

/explorer/

Interactive Dash-based explorer with 7 linked panels: timeline, global map, genome viewer, taxonomy tree, and sequence alignment.

Batch Folding Queue (fold_web)

/help/fold.html · 16.fold_web · internal

ColabFold batch prediction console for the structure atlas: collect → predict → ingest into structures_index (sources += SELF). Live coverage panel, job queue with logs/retry/delete, FASTA/result-ZIP upload, Foldify manual channel. GPU server only — access via SSH port forwarding.

Metabuli

/metabuli/

Metagenomic virus classifier. Upload FASTQ reads or assembled contigs, get taxonomic classification with Krona/Sankey visualization.

FASTQ uploadcontig classification8-rank taxonomyKrona plot

PV-miRNA (PAmiRDB)

/pamirdb/

miRNA-virus target prediction workbench. Custom Smith-Waterman alignment engine with local heuristic recheck layers (no external tools). 11,006 predictions across 799 plant species and 40 virus families.

Sankey diagramnetwork graphposition mapconsensus tier

Virus Phylogeny

/phylo/（one page · two tabs）

Two complementary views: the ICTV MSL41 taxonomy tree (42 families, 200 genera, 2,637 species) with an optional grey non-plant backbone, and 38 official ICTV molecular trees with branch lengths and support values.
