ABOUT THIS PAGE
These are official molecular phylogenies (maximum-likelihood trees) released by ICTV Report chapters — branch lengths are substitutions per site, and node labels are support values. This is a different thing from the taxonomy tree: here every node is a real split inferred from sequences.

DETAIL
Taxonomy source: ICTV Master Species List 2025 MSL41 v1 — 17,554 species / 427 families across all realms. Plant-virus assignment: ICTV VMR Host source (species-level, cleaned by family blacklist).
Molecular trees: ICTV Report chapter resources — ictv.global/report. Files were scraped from each family's Resources page and parsed locally with a stdlib Newick reader. Tip labels are shortened for display (accession and gene/genome boilerplate stripped); hover a tip for the full original name. Genus: mapped from ICTV MSL41 (accession / abbreviation match, constrained to the same family) — the tree files themselves carry no taxonomic ranks. Unmapped tips are greyed out, never guessed.
Note: the taxonomy tree is a taxonomic hierarchy, not a molecular phylogeny — its branch lengths carry no evolutionary distance; switch to the Molecular trees tab for real distances.
